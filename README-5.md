## 📖 About This Repo

This repository contains my **assignment notebooks** for each module of the [Kaggle Computer Vision course](https://www.kaggle.com/learn/computer-vision).

Instead of just completing exercises, I build a **mini-project / assignment after every module** to apply what I learned on real data. This repo is my public proof of work.
